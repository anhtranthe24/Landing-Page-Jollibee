# Jollibee Landing Page Demo

Responsive landing page built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive desktop/mobile layout and animated UI
- Product cards, category filters, sample prices and promotions
- Cart: add/remove items and change quantities
- Demo checkout only: no real order, payment, or backend
- Product photos and fonts load from external sources

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open https://github.com/anhtranthe24/Jollibee
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Replace existing files if prompted.
5. Commit to the `main` branch.
6. Go to **Settings → Pages**.
7. Set Source to **Deploy from a branch**, Branch to **main**, folder to **/(root)**, then Save.
8. Wait for GitHub Pages to finish deploying. The expected URL is https://anhtranthe24.github.io/Jollibee/

## Notes
This is a fan-made learning/demo page, not an official Jollibee website. Names, prices and offers are illustrative. The checkout button only displays a demo message. Images require an internet connection.
